Μπορείτε να αλλάξετε τον κωδικό πρόσβασης που προστατεύει τον κρυπτογραφημένο χώρο. Θα χρειαστείτε τον τρέχοντα κωδικό.

Όταν είναι ενεργή, οι τίτλοι των σελιδοδεικτών δεν εκτίθενται στο overlay UI ούτε στα mutation events μεταξύ tabs. Χρήσιμο για screen sharing / remote support.
