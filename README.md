# Encrypted Carousel Bookmark Flow (ECBF)

Το **Encrypted Carousel Bookmark Flow (ECBF)** είναι μια προηγμένη επέκταση για τον Mozilla Firefox (Manifest V3) που λειτουργεί ως ενιαίος διαχειριστής σελιδοδεικτών. Συνδυάζει τους εγγενείς σελιδοδείκτες του Firefox με έναν ξεχωριστό, πλήρως κρυπτογραφημένο χώρο αποθήκευσης, παρέχοντας απόλυτο έλεγχο στην οργάνωση, τη μεταφορά και την προστασία των δεδομένων σας.

👉 **[Λήψη από το Firefox Add-ons](https://addons.mozilla.org/el/firefox/addon/encryptedcarouselbookmarkflow/)**

## 🗂️ Δύο Χώροι Διαχείρισης
- **Firefox Space**: Χρήση των κανονικών σελιδοδεικτών του Firefox μέσω του Bookmarks API. Οι εγγραφές περιορίζονται στο διαχειριζόμενο υποδέντρο (Bookmarks Toolbar) για ελεγχόμενη πρόσβαση.
- **Encrypted Space**: Ένας ξεχωριστός χώρος στο IndexedDB, όπου οι τίτλοι και τα URLs των σελιδοδεικτών αποθηκεύονται κρυπτογραφημένα με **AES-256-GCM**. Τα δομικά μεταδεδομένα (id, parentId, order) παραμένουν διαθέσιμα μόνο ως ανώνυμα αναγνωριστικά για τη διαχείριση της δομής.

## 🔐 Κρυπτογραφικός Σχεδιασμός
- **Argon2id** (64 MiB, 3 επαναλήψεις) για την παραγωγή κλειδιού από τον κωδικό πρόσβασης.
- **HKDF** για την παραγωγή υποκλειδιών.
- **AES-256-GCM** για κρυπτογράφηση και ελεγχόμενη ακεραιότητα (authenticated integrity).
- **State MAC + Merkle commitment** για την ανίχνευση μη αναμενόμενων αλλοιώσεων.
- **Zeroization** των κλειδιών στη μνήμη κατά το κλείδωμα.
- **State Machine**: Η κρυπτογραφημένη περιοχή χρησιμοποιεί καταστάσεις `LOCKED / UNLOCKING / UNLOCKED / LOCKING`. Το κλείδωμα γίνεται χειροκίνητα ή αυτόματα βάσει του MV3 lifecycle, ενώ υποστηρίζεται και αλλαγή κωδικού με ασφαλή περιστροφή κλειδιών.

## ⚙️ Οργάνωση & Μεταφορά
- Διατήρηση της ιεραρχίας φακέλων/υποφακέλων και της σειράς εμφάνισης.
- **Αμφίδρομη μεταφορά** μεταξύ Firefox και Encrypted Space.
- **Two-phase operations** με δυνατότητα rollback για την αποφυγή μερικώς ολοκληρωμένων μεταφορών.
- **Drag & Drop** για άμεση μετακίνηση αντικειμένων.
- **Multi-select**: Υποστήριξη `Ctrl+Click`, `Shift+Click` και `Ctrl+A`.
- **Αναζήτηση** με αντιστοίχιση προθέματος (prefix matching) και **φωνητική μεταγραφή** (Ελληνικά/Κυριλλικά → Latin).
- Άνοιγμα σελιδοδείκτη σε τρέχουσα ή νέα καρτέλα.
- **Favicons** αποκλειστικά από `tab.favIconUrl` ή data URLs (χωρίς εξωτερικούς διακομιστές).
- Μετονομασία σελιδοδεικτών και φακέλων.
- Κεντρικό μενού `☰` και μενού περιβάλλοντος (δεξί κλικ) στις κάρτες.
- **Strict Privacy Mode** για απόκρυψη τίτλων στο UI (ιδανικό κατά το screen sharing).

## 📤 Εξαγωγή & Εισαγωγή (Export / Import)
Υποστηρίζονται 4 τύποι εξαγωγής:
1. Σελιδοδείκτες (bookmarks)
2. Favicons
3. Κρυπτογραφημένο αντίγραφο ασφαλείας (encrypted backup)
4. Κρυπτογραφημένη απλή εξαγωγή (encrypted plain export) με προειδοποίηση

Η εισαγωγή κρυπτογραφημένου backup υποστηρίζεται με έλεγχο ταυτότητας μέσω του αντίστοιχου κωδικού πρόσβασης. Όλα τα αρχεία εξαγωγής δημιουργούνται **αποκλειστικά τοπικά** μέσω Blob URLs, χωρίς αποστολή δεδομένων σε διακομιστή.

## 🛡️ Αρχιτεκτονική Ασφάλειας
- **Background layer (Trusted Authority)**: Διαχείριση κρυπτογραφικών κλειδιών, κρυπτογράφηση/αποκρυπτογράφηση και IndexedDB.
- **UI layer (Client)**: Χωρίς άμεση πρόσβαση σε κρυπτογραφικά κλειδιά ή προστατευμένη αποθήκευση.
- **HMAC-signed communication** με επικύρωση session, epoch και sequence.
- **Single Writer / Mutation Sequencer**: Σειριοποίηση μεταβολών και περιορισμός race conditions.
- **State integrity mechanisms**: State MAC και Merkle commitment.

## 🌐 Μηδενικό Δίκτυο (Zero-Network)
Το ECBF δεν απαιτεί cloud, backend, εξωτερική βάση δεδομένων ή online λογαριασμό. Δεν αποστέλλει σελιδοδείκτες ή κρυπτογραφημένα δεδομένα σε τρίτους. Τα δεδομένα, τα κρυπτογραφημένα vaults και τα αρχεία export/import παραμένουν **τοπικά στον Firefox**.
